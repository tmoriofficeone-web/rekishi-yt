# rekishi-yt — 歴史の裏側ラボ 自動投稿ツール

「歴史の裏側ラボ」（https://www.youtube.com/channel/UC8YKL6AHWldt3fY4ZVsIP3Q）の動画を、運営者自身のチャンネルへ毎日自動投稿するための個人用ツールです。

本ツールは **YouTube API サービス** を利用しています。
This tool uses YouTube API Services.
