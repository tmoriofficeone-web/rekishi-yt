# rekishi-yt プライバシーポリシー / Privacy Policy

本アプリ「rekishi-yt」（以下、本アプリ）は、運営者（森 隆浩）本人が所有するYouTubeチャンネルへ動画を自動投稿するための、運営者専用のツールです。
"rekishi-yt" (the App) is a single-user tool operated by Mori Takahiro to upload videos to his own YouTube channel.

## YouTube API サービスの利用 / Use of YouTube API Services
本アプリは YouTube API サービスを利用しています。本アプリを利用することで、YouTube 利用規約（https://www.youtube.com/t/terms）および Google プライバシーポリシー（https://policies.google.com/privacy）に同意したものとみなされます。
The App uses YouTube API Services. By using the App you agree to the YouTube Terms of Service and the Google Privacy Policy linked above.

## 取得・保存する情報 / Data collected and stored
- 運営者自身のYouTubeアカウントの OAuth トークン（アップロード権限）
- 運営者自身がアップロードした動画のID・再生回数
上記以外の情報（他のユーザーやチャンネルのデータ）は一切取得しません。
Only the operator's own OAuth token and the IDs/view counts of the operator's own videos are stored. No data of other users or channels is accessed.

## 保存先と共有 / Storage and sharing
運営者が管理する実行環境（GitHub Actions の暗号化 Secrets およびリポジトリ）にのみ保存し、第三者への提供・販売は一切行いません。
Data is stored only in the operator's own environment and is never shared or sold.

## データの削除と権限の取り消し / Deletion and revocation
保存データは30日ごとに見直し、不要になったものは削除します。運営者は Google セキュリティ設定（https://myaccount.google.com/permissions）からいつでも本アプリの権限を取り消せます。
Stored data is reviewed and purged as needed; access can be revoked at any time at https://myaccount.google.com/permissions.

## Cookie
本アプリは Cookie を使用しません。The App does not use cookies.
